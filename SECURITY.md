# Security

If you find a way to make Adytum cross a boundary it should hold, report it privately through this repository's security advisories (the **Report a vulnerability** button under **Security**), not in a public issue.

Say what you found, how to reproduce it, which version you ran (`adytum --version`), and on which system. Say what had to be running already, under which account, and what it could then read or change. You will get an answer within seven days. Adytum is at 0.x, so fixes go into the latest release only.

The scope is this repository: the `adytum` command and the `adytum` library.
